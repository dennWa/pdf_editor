# PDF-Editor

Bearbeite PDFs direkt im Browser: https://dennwa.github.io/pdf_editor/

- PDF öffnen (Klick oder Drag & Drop), mehrere Dokumente gleichzeitig
- Jedes Element einzeln erkennen und löschen: Text, Logos/Bilder, Linien, Unterschriften, Stempel, Wasserzeichen
- Text per Doppelklick ändern – in der Originalschrift der PDF (Schriftart, Größe, Stärke, Farbe bleiben gleich)
- Formularfelder, Stempel und Scans: Feldinhalte einzeln bearbeitbar, Texterkennung (OCR) für eingescannte Seiten, „Abdecken“ in Hintergrundfarbe
- Neuen Text, Bilder und Unterschriften (zeichnen oder hochladen) einfügen
- Speichern als PDF, Word (.docx), PNG/JPG oder Projektdatei (.pdfprojekt) zum Weiterbearbeiten

Alles läuft lokal im Browser – Dateien werden nirgendwo hochgeladen.

Verwendete Bibliotheken (in `vendor/`): pdf.js (Apache 2.0), pdf-lib (MIT), docx (MIT), JSZip (MIT), Tesseract.js (Apache 2.0).
